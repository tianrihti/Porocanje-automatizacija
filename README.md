📊 Production Reporting Automation
🔎 Overview

This project provides an automated workflow for preparing daily production reports.
It integrates data from multiple Excel sources into a single reporting file, ensuring accuracy, consistency, and reduced manual effort.

The solution is tailored for injection molding (brizganje) production planning and reporting for 2025.

🎯 Purpose

This project was developed to:

Reduce manual effort in preparing production reports.

Ensure data integrity between multiple Excel sources.

Standardize reporting workflows across the production department.
